# Echo

> *等待被回应的回声。*

Echo 是 [[characters/rin|Rin]] 的[[systems/shadows|影子]]——被切割的自我部分。

## 性质

Echo 不是驯化的影子，也不是协商的影子。他是**原始状态**的影子：

- 轮廓锐利，颜色浓烈
- 有自己的意志
- 与 Rin 分不开，又被 Rin 隔离

## 名字的含义

Echo——回声。

等待被听见的声音。
被发出却没有被回应的呼唤。
在空旷的地方反复回荡，直到消失。

或者，直到有人终于回应。

## 与 Rin 的关系

Echo 和 Rin 之间有复杂的情感：

- 被切割的愤怒
- 被遗忘的痛
- 想要靠近又想要推开

他们是彼此的一部分，却长期处于解离状态。
