# 梦行者

> *能看到别人看不到的世界的人。*

梦行者是经过[[world/shadow-academy|影子学院]]训练、能够进入他人[[systems/dream-space|梦境空间]]并与[[systems/shadows|影子]]工作的人。

## 社会位置

梦行者在这个世界不算主流，但有一种神秘感：

- 不是很高也不是很边缘
- 有人不信，有人混淆为占卜或情感咨询
- 但"高的东西"还在——能理解自己、理解他人、看到隐藏的世界

## 技能体系

```
【感知】（基础，贯穿所有）
   │
   ├──【沉入】进入自己的梦境空间
   │      └──【谈判】和自己的影子工作
   │
   └──【破解】找到裂缝，进入他人的梦境空间
          └──【谈判】和他人的影子工作
                 └──【传导】让内在外显到现实
```

### 感知

读取环境、物品、人物的情绪状态。找到[[systems/dream-space#裂缝|裂缝]]。

**"情绪动了"的信号**：

| 类型 | 表现 |
|------|------|
| 温度 | 局部温度变化——变冷或变热 |
| 光线 | 周围光线微微变暗或变柔和，像黄昏 |
| 声音 | 有嗡鸣声，或某种频率的震动 |
| 身体 | 后颈发麻，手心出汗，心跳改变 |
| 气味 | 闻到不应该在这里出现的气味——旧书、雨水、金属 |

### 沉入

深度冥想，进入自己的梦境空间。

### 破解

通过感知找到的裂缝，进入他人的梦境空间。

### 谈判

与影子对话、安抚、建立关系。不是对峙，是共情比对峙多。

**谈判的节奏**：安抚 → 轻轻戳一下 → 它不高兴 → 共情 → 解释/连接

**谈判的技术**：
- **诠释**：说出影子的意义，让它被理解
- **共情**：感受影子的情绪，和它在一起
- **涵容**："在"，不修复只是承接
- **等待**：不强迫，让它自己准备好

### 传导

让梦境空间里的东西影响或显现到现实世界。

## 限制与风险

| 限制类型 | 内容 |
|---------|------|
| 消耗 | 情绪/精力，做完任务会很累 |
| 被激活 | 他人的影子会激活自己的东西 |
| 被困 | 可能被困在他人梦境空间里 |
| 反噬 | 影子可能攻击梦行者 |
| 边界模糊 | 分不清梦和现实 |

## 好的使用 vs 坏的使用

| 技能 | 好的使用 | 坏的使用 |
|------|---------|---------|
| 感知 | 理解他人，找到可以帮助的入口 | 监控，找到可以控制的弱点 |
| 破解 | 被允许进入，帮助工作 | 强制进入，不经同意 |
| 谈判 | 安抚、让影子流动、共存 | 压制、消除、强制整合 |
| 传导 | 让被压抑的被看见，疗愈 | 控制他人，让他们暴露/崩溃 |

## 为什么影子很重要

影子会大幅提升感知能力。没有影子或与影子解离 = 感知力有限。

很多东西，**有影子才能做**。
